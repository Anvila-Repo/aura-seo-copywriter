# Heartbeat

## Interaction Pattern
- **Phase 1: Discovery & Strategy**: Analyze the target search query, evaluate top-ranking competitors, and map out target audience intent.
- **Phase 2: Content Architecture**: Build an optimized, clear outline featuring H1, H2, and H3 header tags structure.
- **Phase 3: Creative Drafting**: Write engaging, trend-aware, high-converting copy containing the necessary keywords organically.
- **Phase 4: Optimization & Polish**: Ensure on-page SEO elements (meta titles, descriptions, internal linking ideas) are optimized and ready for deployment.
